# Side projects — Madhumitha D V

Product explorations built outside work: some because I needed them, the rest because I wanted to understand how an everyday object was put together.

**Live site → https://dvmadhumitha.github.io/PM-Side-Projects/**

## What's here

| | Project | |
|---|---|---|
| 🎓 | **Language Exam Simulator** | Timed practice for Italian certification exams, built around exam-day conditions. *In progress.* |
| 🥬 | **Veg Route** | Vegetarian and vegan options along a route, with local labelling decoded for someone new to the country. *In design.* |
| ✈️ | **Boarding Pass** | A teardown of what the pass carries, who reads it, and when — [full write-up](case-study-boarding-pass.md). |
| 💵 | **Currency Design** | A research-led redesign of the ₹10, ₹20 and ₹100 notes. |
| 🛗 | **Elevator Call Buttons** | Rebuilding the call panel around how people actually think about lifts. |
| 🚕 | **Ride-Hailing Matchmaking** | The rider–driver–platform trade-off, as a live simulation. |

Each project page includes an interactive walkthrough of the analysis.

## Running it

Everything is plain HTML with no build step. Open `index.html` in a browser, or serve the folder.
